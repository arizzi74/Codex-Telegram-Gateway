# v0.5.79

The desktop and mobile Web UI now show a glowing green **Goal** button in the
top bar when the selected session has an active goal. Press it to open a
scrollable popup containing the goal text.

The indicator loads the selected session's current goal after connecting and
updates through live goal-change notifications without periodic polling. It
hides when the goal pauses, completes, is blocked or limited, or is cleared.
Switching sessions, disconnecting or signing out also closes and clears the
popup, so another session's goal cannot remain on screen.

The popup supports keyboard dismissal and safe plain-text rendering. The green
button respects reduced-motion preferences. Goal reads stay scoped to the
validated session and do not modify the goal or start a model turn.

Update workers and reload the Web UI. Older workers and runtimes that do not
support goal reads continue to work with the indicator hidden.
