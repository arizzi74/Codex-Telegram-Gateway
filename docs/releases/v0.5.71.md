# v0.5.71

`/usage` now offers token activity and banked usage resets in Telegram and the
desktop/mobile Web UI. Reset details include the available count, expiry dates
and individual choices. Select a reset, review its account-wide effect, then
confirm to redeem it. `/usage resets` opens the reset list directly;
`/usage redeem` asks for confirmation before using the next available reset.

The worker refreshes availability before redemption and reports the updated
limits afterward. Cancellation, expired selections, account changes, worker
restarts and repeated button presses cannot silently redeem another reset.
Unconfirmed requests are not automatically retried. Older runtimes and accounts
that do not report banked resets show that limitation explicitly.

`/usage daily`, `/usage weekly` and `/usage cumulative` display account token
activity as dated text. Weekly totals use Sunday–Saturday periods, matching
Codex. Background status reads remain lightweight; reset details are fetched
only when you open the usage/reset menus.

Update both gateway and workers for these menus, then refresh open Web UI tabs.
Codex must support the earned-reset API (verified with official Codex 0.157.1).
Regression tests use simulated accounts; no real reset credits are consumed.

API reference: [earned rate-limit resets](https://learn.chatgpt.com/docs/app-server#8-earned-rate-limit-resets-chatgpt).
