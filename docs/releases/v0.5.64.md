# v0.5.64

Gateway backup retention now recognizes SQLite's optional WAL, shared-memory,
and rollback-journal files. These files can accompany a verified database
backup and are retained or removed with that backup's directory.

This corrects v0.5.63 skipping those gateway backups as unrecognized folders.
The policy remains one complete backup for each of three previous versions,
applied only after a successful update. Worker retention is unchanged.
