# v0.5.99

Managed-bot creation now refreshes the selected manager's own Telegram profile
with `getChat` before checking `getMe`. This recovers from stale management-mode
flags after a BotFather change, including newly enabled or disabled management.
Only the verified, refreshed capability can allow a creation request.

**Refresh manager bots** now performs the same profile refresh for enabled bots
and bypasses the gateway's metadata cache. It uses the current authenticated
session with the usual Origin and CSRF checks. Background dashboard and pending
request polling retain their cached reads.

Profile lookup failures are reported as verification errors, and disabled
management is reported only after a successful refresh. Failed verification
does not create an intent or change a webhook. Disabled bots remain disabled.

Regression coverage includes stale flags in both directions, lookup failures,
identity mismatches, cancellation, disabled-bot isolation, authenticated refresh,
and desktop/mobile refresh behavior during an existing cached read.
