# v0.5.60

This release fixes automatic Codex runtime updates blocked by group-writable
standalone release directories.

- Runtime snapshots and rollback accept group-writable files and directories
  owned by the updater's account, matching normal standalone installation checks.
- Validation reports the affected installation component and the actual failure
  instead of the misleading message “previous Codex release ownership changed.”
- World-writable paths, incorrect owners, unexpected file types, changed release
  contents, and invalid package identities remain rejected. Recovery journals
  retain their private permissions, and updates still wait for idle workers.

The permission validation failure does not set a persistent rejected-version
flag. Once the corrected updater is installed, its next scheduled maintenance
attempt can proceed when the worker is idle.
