# v0.5.68

`/tgsteer` now accepts attached images in Telegram and the web UI. Use it as the
image caption, optionally followed by instructions. The image and text target
the running turn together; a completed or replaced turn cannot receive them.
Image-only steering is supported. Other slash captions in Telegram remain
literal prompt text.

On mobile, **Stop** now sits immediately left of **Steer**. The empty composer
keeps its idle height, including after clearing a typed message; multiline
input still expands normally.

Telegram's **Reply with text** helper no longer forces the app to select a reply.
It explains how to long-press the question, choose **Reply**, and send an answer.
Previously prepared helpers also have their forced-reply setting removed before
delivery. Answers still target the original question without changing the
selected session, and answered helpers are cleaned up as before.

Telegram may retain a reply preview already saved on a phone. Tap **×** once to
clear it; the bot cannot dismiss that existing client-side draft. Clear a reply
to a question before sending an image, since question answers accept text only.
