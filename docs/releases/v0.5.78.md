# v0.5.78

`/status` in Telegram and the Web UI now shows the running Codex runtime
version, remaining account allowances instead of percentages used, and each
reported limit's reset date and time in UTC.

Window labels follow the duration reported by Codex, so the weekly allowance
is identified whether it appears as the primary or secondary limit. Missing
version, duration or reset details are reported without inventing values.

The context usage percentage still describes the session's context use.
`/usage` and its banked-reset controls are unchanged.

Update workers to receive the new command output. Active turns finish before
queued worker updates restart their runtime.
