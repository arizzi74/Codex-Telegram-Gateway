# v0.5.83

Ordinary Telegram messages now steer the addressed session's active turn, using
the same behavior and acknowledgement as `/tgsteer`. When no turn is active,
they start a new turn. This includes session shortcuts, photos, and uploaded
images with or without captions.

Image routing preserves the session and turn selected before downloading the
attachment. If that turn finishes or is replaced during the download, the
gateway rejects the stale steering request instead of starting or steering a
different turn.

Replies to pending questions, session-creation input, and explicit slash
commands keep their existing behavior. The change is implemented in the gateway;
existing workers already support the required steering operation.
