# v0.6.3

The Web UI now has a Telegram bot selector beside the connection status.
Options show the bot's base display name without its inherited session suffix.
Unassigned sessions show **<no bot>**.

Selecting a bot moves its private Telegram conversation to the current session.
Each session has one bot: selecting another bot in the Web UI or through
Telegram's `/tgsessions` disconnects the previous one. Selecting **<no bot>**
clears the assignment. Group and forum-topic selections remain independent.

Assignments update across open browser views through the activity WebSocket,
without reloading session history. The activity protocol remains compatible
with earlier browser clients. Changes preserve accepted command targets and
shared question handling.
