# v0.5.80

Completed Codex answers now render Markdown in Telegram instead of exposing
formatting markers. Bold, italics, strikethrough, inline and fenced code, headings,
and web links use Telegram message entities. Markdown tables become labeled
rows that fit mobile screens; local file links retain their readable paths.

Formatting is built after secret redaction and before splitting long answers.
Rendered text and hidden link destinations are checked again after Markdown
normalization, so formatting or escaped characters cannot undo redaction.
Each chunk retains valid Unicode offsets and formatting, including when
multisession headers are added or removed. Long replies are split once, avoiding
tiny intermediate messages caused by reserving session headers after splitting.

This is a gateway update. Workers need no update for this correction. Previously
delivered Telegram messages retain their original appearance.
