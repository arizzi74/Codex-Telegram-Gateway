# v0.6.6

Telegram questions and approvals now go only to the session's assigned bot by
default. Each bot's Admin configuration includes **Broadcast session questions
to all bots**, off by default. Enable it on the assigned bot to notify all
enabled, authorized bot chats. Sessions without an assigned bot always notify
all eligible bots.

Follow-up questions use the same routing rule. Answers from any delivered copy
still update every copy, and `/tgquestions` can open pending requests manually
without changing the selected session. The preference survives gateway
restarts, profile refreshes and token replacements.

The gateway applies a SQLite migration with the new preference off for existing
and newly connected bots. Settings changes retain the Admin authentication,
Origin and CSRF requirements.
