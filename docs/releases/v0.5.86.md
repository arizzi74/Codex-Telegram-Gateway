# v0.5.86

The admin console now offers **Delete** for revoked workers. Its confirmation
identifies the worker and explains that the action permanently purges the
worker and all its related gateway database records. Project files and native
Codex sessions on the worker remain untouched.

Permanent deletion requires recent authentication and explicit confirmation.
Enabled workers must first be revoked. The database purge is atomic and keeps
unrelated workers and administrator access intact.
