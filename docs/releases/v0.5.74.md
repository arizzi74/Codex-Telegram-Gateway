# v0.5.74

Web UI conversation history now preserves Codex's per-item timestamps. Messages,
tool calls and reasoning entries from the same turn can show their own recorded
times after reconnecting or reloading the page.

When older history supplies only the turn's start time, the date is labeled
**Turn started**. Completion-only and browser-observed times are also labeled;
missing dates are not invented. Loaded conversation exports and history commands
keep these distinctions.

Update both the gateway and workers to preserve native history timestamps end to
end, then reload the Web UI. Older conversations without recorded per-item dates
continue to show the labeled fallback.

Validation covers timestamp units, invalid dates, live events, reconnects,
pagination, exports, and narrow mobile layouts.

The release also updates the Go build requirement and affected dependencies to
the versions required by the current vulnerability checks.
