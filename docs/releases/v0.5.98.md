# v0.5.98

The admin console can now connect multiple Telegram bots to one gateway. Choose
**Connect existing bot** to submit a BotFather token, or **Create managed bot**
to prepare a Telegram creation link and connect the resulting bot automatically.
Managed creation requires Bot Management Mode on the selected manager bot.

Bots share the configured gateway owner and worker inventory, while chat session
selections, callbacks, notifications, voice notes, and audio replies use the
correct bot independently. The existing primary bot and its routing ID are
preserved.

Additional credentials are encrypted with a private companion key next to the
SQLite database. Gateway update backups include that key and retain the existing
three-version backup policy. Back up the database and key together for recovery.

The console supports disabling, enabling, replacing an additional bot's token,
and removing its gateway bindings. Changes require recent authentication.
Webhook takeover needs explicit confirmation, managed creation requests expire
after 15 minutes, and ownership changes disable managed bots until ownership is
verified again. Disabled or removed bots cannot replay queued private responses
when reconnected. Removing a bot keeps worker sessions and project files.

Validation includes the Go suite, vet, desktop/mobile browser tests, and targeted
race tests for bot routing, lifecycle, encryption, and request isolation.
