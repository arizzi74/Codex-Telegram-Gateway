# v0.5.72

Worker setup now needs only a display name and a one-use enrollment URL. Choose
**Enroll worker** in the passkey-protected admin console, copy the short URL,
and run the same installer command on the worker machine. The installer retrieves
the gateway address, worker ID and token automatically, starts in the user's
home directory, and installs and authenticates Codex when needed.

Enrollment URLs expire after 10 minutes, can be redeemed once, and create the
worker only when the installer submits its name. Opening the URL in a browser
does not consume it. The admin dialog includes copying, a countdown, revocation
and replacement. Restricted Linux service access is the default; choose full
account permissions in the dialog before copying the URL. Replacing a URL or
changing its access revokes the previous unused URL first. Failed requests are
never automatically replayed, and enrollment URLs and worker tokens stay out of
browser storage.

Redeemed credentials are saved in durable private recovery storage before
service installation. If installation is interrupted, rerun the installer to
resume the saved worker identity without another enrollment. A lost redemption
response requires checking the admin worker inventory and revoking any incomplete
worker from that attempt before creating a fresh URL; it is never replayed.

Existing workers, private prepared configurations and token rotation remain
supported. Update the gateway and installer together for the new enrollment
flow, then refresh open admin tabs. Regression tests use simulated enrollment
credentials and do not enroll a live worker.
