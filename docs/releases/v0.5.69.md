# v0.5.69

Switching to a running session through `/tgsessions` restores Telegram messages
in a consistent order: the connection confirmation, Codex's latest temporary
commentary, then the temporary tool message.

The tool waits until available commentary has been delivered, including after
Telegram retries or a gateway restart. Turns with no commentary can still show
their tool message. Later progress updates replace the same messages in place;
switching away and turn completion retain their existing cleanup behavior.
