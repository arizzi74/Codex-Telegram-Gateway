# v0.5.76

Web UI history now recovers recorded timestamps for subagent activity, including
interactions and completions. These entries previously shared the enclosing
turn's start date even when their saved events contained individual dates.

The worker matches activity entries by their exact saved event identity,
separately from tool calls that can share the same identifier, and recognizes
the core item names used in saved lifecycle events. Completions that
arrive after a parent turn ends retain that turn's identity. Dates recovered
from saved records are labeled **Recorded**.

Existing timestamp indexes receive a bounded, one-time rebuild so previously
cached history gains the missing dates. Progress survives worker restarts;
normal incremental reads and background indexing limits remain in place.

Update the gateway and workers, then reload the Web UI. Older entries may gain
their dates as the bounded backfill progresses. Missing or ambiguous dates
continue to show the explicit **Turn started** fallback.
