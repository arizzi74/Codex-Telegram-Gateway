# v0.5.62

Temporary Telegram text-reply prompts are removed when their questions are
answered or dismissed. Browser sign-in can be renewed without leaving the
conversation, with recovery controls for expired logins.

- The extra **Answer for <session>** message is deleted while the original
  question retains its **Question / Answer** summary. Partial answers preserve
  the remaining questions. Cleanup follows reported answers and resolutions from
  other interfaces, survives restarts, and handles messages already in flight.
- Upgrading schedules cleanup of recorded, resolved helper messages in indexed
  batches. Known messages beyond Telegram's 48-hour deletion window are skipped.
  If Telegram retains an old reply preview, close it with **×**; `/tgquestions`
  shows the requests that are actually pending.
- Browser logins retain their absolute eight-hour lifetime. Five minutes before
  expiry, the admin console and Web UI offer **Continue with passkey**. Renewal
  replaces the old login token and retains notification subscriptions. Running
  Codex turns continue if the browser locks or disconnects.
- Signing in again restores the selected conversation and reading position.
  Mobile foreground checks and cross-tab revalidation detect expired or revoked
  access, and locked views clear private conversation data.
- Optional encrypted text-draft recovery is off by default. The gateway stores
  ciphertext for up to 30 minutes after its latest save; the key stays in the
  browser tab. Recovery requires explicit restoration and never submits a
  prompt automatically. Images are excluded.
- The admin console lists browser logins and supports individual revocation or
  signing out everywhere. Passkey changes and worker enrollment, revocation,
  and token rotation require passkey verification within the previous five
  minutes.

This update includes SQLite migrations 017–019 and requires a gateway restart.
Refresh already-open browser pages to load the new interface. Existing workers
remain compatible; no Codex runtime update is required for these changes.
