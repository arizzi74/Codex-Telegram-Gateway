# v0.5.90

Telegram voice notes can now become Codex prompts using local transcription.
The gateway converts Ogg/Opus audio entirely in Go and sends PCM to a bundled
Whisper helper. No transcription API key, FFmpeg, Python, or additional runtime
audio libraries are required.

Enable it on the gateway host after updating:

```sh
sudo codex-telegramgw setup voice
```

Setup verifies the helper and multilingual base model before enabling the
feature. The model stays loaded between recordings, with two inference threads
and one recording processed at a time. Voice notes may be up to five minutes
and 20 MiB. MP3/M4A files and video notes are not supported in this release.

The durable queue preserves the destination selected when a recording arrives.
Idle-session recordings become prompts, active-turn recordings become steers,
and replies to free-text questions become answers. Recognized slash commands
remain ordinary text. Duplicate deliveries, restarts and stale turns are fenced
before a transcript can be submitted. Temporary transcription feedback is
removed after completion; the transcript remains visible like a text prompt.

Redistributable helpers are built and tested on Linux and macOS, each for amd64
and arm64. Linux helpers are statically linked; macOS helpers use system
libraries only. Gateway updates include the matching helper in their existing
backup and rollback handling. Workers need no voice-specific configuration.
