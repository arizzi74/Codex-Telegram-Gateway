# v0.6.7

Telegram now accepts generic document uploads up to 10 MiB each. The selected
worker saves them in the session's working directory under `inbound/`, creating
that directory when needed. Filenames receive a unique suffix and existing
files are not overwritten.

Without a caption, the bot confirms the saved absolute path and does not
contact Codex. With a caption, the saved path is appended to the instructions
and submitted as a prompt, or as steering input when a turn is active.
Supported photos and image documents keep their existing image-input behavior.

Uploads retain the original session and working directory if the user switches
sessions while downloading. File saving rejects symbolic-link redirection and
supports retrying an accepted upload without creating another copy. Worker
capability checks explain when an update is required instead of discarding a
file or its caption.
