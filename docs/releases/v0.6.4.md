# v0.6.4

The Web UI Telegram bot selector now recovers the base display name of a
managed bot whose older registration has no recorded manager. It uses the
matching owner's completed creation request, so the selector can show the
original name without an inherited session suffix. Registrations with a known
manager continue to use only that manager's completed request.

The one-bot-per-session assignment behavior from v0.6.3 is unchanged: choosing
a bot here or through `/tgsessions` disconnects the session's previous bot and
updates other browser views immediately.

A worker update test now waits for the approval notification to finish
forwarding before checking the approval-specific blocker. This removes a
timing-dependent assertion failure without changing the worker's update guards.
