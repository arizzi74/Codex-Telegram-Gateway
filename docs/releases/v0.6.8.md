# v0.6.8

Telegram bot names now use the same authoritative base name as the Web UI bot
selector. Managed bots recover their name from the matching owner's completed
creation request, including historical registrations without a saved manager.
Bots without a matching creation record keep their captured original name.

This fixes names such as `EnkiCodex · Fix Telegram gatewa… · Assessment_sic_medico`:
the bot now displays `EnkiCodex · Assessment_sic_medico`. Session switches,
disconnects, inheritance changes and gateway restarts continue to use the clean
base. Captured originals remain unchanged as a fallback; the gateway does not
strip arbitrary text from bot names.

Regression tests cover the historical registration, authoritative owner and
manager matching, name synchronization and restoration, and restart behavior.
