# v0.5.67

The web UI status bar now shows the session's confirmed permission mode beside
the model and reasoning effort. It distinguishes standard presets, named
profiles, custom policies and external sandboxes. Hover for sandbox, approval
and reviewer details; use `/permissions` to change the setting.

The label follows native WebSocket updates from browser, Telegram and CLI
changes. Reconnecting clears stale values, and late resume responses cannot
overwrite newer settings. Missing metadata displays `Permissions ?`.

The mobile status bar keeps two lines, shortening long names as needed. This
release also includes v0.5.66's search-detail and empty-compaction-block fixes.
