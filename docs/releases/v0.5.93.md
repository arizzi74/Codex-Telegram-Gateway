# v0.5.93

The Admin console now includes **Audio support in Telegram**. Enable or disable
voice-note transcription, download the multilingual Whisper base or small model,
and choose inference threads without editing server configuration or restarting
the gateway. The page shows CPU and RAM resources, recommends base and one fewer
thread than available CPU cores (at least one), and reports download progress.
Existing model and thread selections are preserved.

Audio replies are optional and disabled by default. Enable them to receive a
voice-note turn's final answer as both text and audio. Speech runs locally using
Golem's Go implementation of Pocket TTS, with stock English and Italian voices.
The gateway also encodes Telegram Ogg/Opus voice messages in Go. No speech API
key, additional subscription, Python, FFmpeg, or separate TTS executable is
required. Voice models download only when this option is enabled.

Final text arrives first; long spoken answers are split without summarizing.
Durable delivery checkpoints retain completed audio parts across restarts, and
authorization is checked before synthesis and upload. Incoming recordings and
generated audio remain in memory. Transcription and synthesis share the selected
CPU budget, and changing settings lets the current transcription finish first.

Model downloads use pinned revisions, exact sizes and SHA-256 verification.
Admin changes require a recent authenticated session and CSRF protection.
The existing `setup voice` command reads saved Admin choices when options are
omitted and keeps the CLI and Admin settings synchronized with rollback on
failure.
