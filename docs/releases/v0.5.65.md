# v0.5.65

The web UI sidebar now keeps only a Settings link beneath the session list,
giving sessions the remaining vertical space. Settings opens a dialog with
encrypted draft recovery, notification controls, and the operations console
link. Existing preferences are preserved.

The dialog fits desktop and mobile screens, supports keyboard navigation and
Escape, and scrolls when space is limited. Opening it on a phone closes the
session drawer without opening the keyboard. If sign-in expires, the dialog
closes so authentication remains accessible.
