# v0.5.70

The Web UI renders Mermaid diagrams in Codex responses on desktop and mobile.
Diagrams follow the selected theme and fit the conversation width, with zoom,
Fit and Source controls. Invalid or incomplete diagrams retain readable code.

The library is bundled into the Go gateway and renders locally in an isolated
browser sandbox. It needs no CDN, external diagram service or additional server
runtime. Images and diagram results are kept only in browser memory and cleared
when switching sessions or signing out. Browser checks cover responsive sizing,
rendering, theme changes, malformed content and sandbox boundaries.

Refresh an open Web UI tab after updating the gateway. No worker or Codex runtime
update is required for this feature.
