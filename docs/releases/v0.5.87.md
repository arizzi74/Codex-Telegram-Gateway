# v0.5.87

Markdown links to project files in the Web UI are now visibly clickable. Select
a link to see its worker, path and size in a dialog, then choose **Download**.
The conversation stays open on desktop and mobile, including for older messages.

Downloads come from the session's worker through an authenticated, temporary
stream. They do not launch another Codex process or store file contents in the
gateway database. Reads are limited to regular files within that session's
project, with path, symlink, size and connection checks.

Update the gateway and workers to this release, then refresh the Web UI. Older
workers show an update instruction when a file is selected.
