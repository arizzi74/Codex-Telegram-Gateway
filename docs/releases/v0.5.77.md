# v0.5.77

Web UI history now recovers message timestamps in turns containing recognized
image or audio inputs. Previously, an attachment disabled timestamp matching
for every message in its turn, while neighboring tool entries could still show
their individual dates.

Paging through a running turn also retains dates for entries that have not yet
been viewed. The worker verifies the saved sequence for the original snapshot
and limits matches to that prefix, so later messages, including repeated text,
cannot invalidate or supply dates for earlier entries.

Existing timestamp indexes rebuild incrementally once to add these prefix
proofs. The index remains metadata-only, with the same scan and cache limits.
Unknown or malformed input projections and incomplete saved records continue
to use the explicit **Turn started** fallback.

Update workers and reload the Web UI. Older history may gain dates as bounded
backfill progresses.
