# v0.5.92

Voice setup now supports the multilingual Whisper small model and configurable
CPU inference threads:

```sh
sudo codex-telegramgw setup voice --model small --threads 3
```

Base and small models are downloaded from immutable revisions and verified by
size and SHA-256 before use. Setup validates the selected model with the helper
before restarting the gateway. Fresh installations keep the base/two-thread
default; repeated setup preserves the existing supported model and thread
selection when those options are omitted. Gateway updates preserve the settings.

Go configuration and helper-client validation now accept 1–32 inference
threads, matching the native helper. Audio recordings and converted PCM remain
in memory and pass through a pipe; no recording files are saved on the gateway.

Gateway update-backup retention now recognizes the optional Whisper helper
snapshot, while continuing to preserve unknown files and legacy backup layouts.
