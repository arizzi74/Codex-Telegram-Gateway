# v0.6.2

Expired managed-bot setup requests now provide recovery controls in the
Operations console. **Create new link** checks the manager and username again
and replaces the old request with a fresh 15-minute confirmation window.
**Delete request** removes an abandoned setup request after confirmation, and
**Connect existing bot** opens token-based connection if the bot was already
created in Telegram.

Removing a setup request does not delete a Telegram bot. Requests already
claimed for activation or connected to a bot are protected from these actions.
Retries preserve the original request when checks or saving the replacement
fail, and late Telegram callbacks cannot claim a removed request.
