# v0.5.91

Fix local transcription of voice notes recorded in Telegram for iOS. Its
encoder can finish by flushing complete Ogg/Opus pages without marking an
explicit end-of-stream page. The Go decoder now accepts that clean end of file
and uses the last validated audio granule to determine the recording length.

Checksum, page sequence, packet completeness, stream identity, and audio size
and duration checks remain enforced. Truncated pages and unfinished packets
are rejected. Audio conversion and transcription still run locally, without
FFmpeg or a transcription API.

Voice downloads also verify Telegram's declared file size when available, so
a shortened download cannot be mistaken for an intentionally finished recording.

Update the gateway to receive this correction. Existing voice configuration
and the downloaded Whisper model are preserved; no worker update is needed.
