# v0.5.57

This release publishes the browser interface alongside the Telegram gateway,
with connection improvements, mobile notifications and a public project website.

## Browser interface

- Open `/tgw/webui/` and use the existing admin passkey to select sessions across
  workers. The interface attaches to an existing Codex app-server without a
  separate terminal process.
- Read the latest 20 entries, retrieve older history on demand, paste images,
  use slash-command menus, answer questions, and steer or interrupt turns.
- Session state and confirmed model/reasoning changes update other open views
  through WebSockets. On phones, the menu is green while any session is running;
  pending questions take priority with a yellow question mark.
- Connection progress distinguishes transport connection, session restoration,
  and history loading. Worker observer admission respects cancellation and
  reuses confirmed subscriptions. Slow legacy history reads do not block the
  relay's native event reader.
- Enable optional Web Push notifications for completed turns across all visible
  user sessions. iPhone and iPad require a Home Screen installation. Alerts use
  generic text and open the affected session after normal authentication.

The [browser guide](../webui.md) covers the command catalog, responsive controls,
notification setup, compatibility and connection behavior.

## Worker and runtime updates

This release also includes the previously staged support for secure private
Codex socket layouts, runtime compatibility preflight checks, and recovery after
a failed runtime update. Existing update safety checks continue to protect active
work. Official Codex builds remain in use.

## Upgrade

Update the gateway and workers to enable the complete browser feature set.
Gateway routes now live under `/tgw/`; follow the
[route migration instructions](../installation.md#upgrade-to-the-tgw-url-routes)
when upgrading from an earlier public release, including the reverse-proxy
WebSocket routes. The gateway applies its SQLite migrations on startup.

The [project website](https://arizzi74.github.io/Codex-Telegram-Gateway/) includes
desktop and mobile screenshots captured with Playwright using fictional demo
data. [Website maintenance](../website.md) explains how to reproduce them.
