# v0.5.66

Web search entries now display their full queries, page URL or find pattern,
and any search results supplied by Codex. Results are rendered as safe text
with the same output-size limit as other tools.

Context compaction now appears as a plain activity line, with live progress
and completion labels. It no longer opens an empty block. Other tools without
details also omit the expander; their output becomes expandable when it arrives.

Browser regression checks cover saved and live search actions, result rendering,
compaction state, empty tool output, and untrusted markup.
