# Passkey administration

Context: the user explicitly requested an administration web interface, overriding
the specification's browser UI non-goal.

Decision: provide a same-origin admin interface authenticated with WebAuthn
passkeys, requiring user verification. Initial registration needs a short-lived,
one-use bootstrap token generated by a local administrative command.

Consequences: public first-visitor enrollment is prohibited. The owner registers
their authenticator in a browser at the configured HTTPS origin.

Amendment (2026-10-10): the owner can explicitly enable username/password
authentication in the console, alongside passkeys. It remains disabled by
default and cannot bootstrap the first owner. Argon2id hashes are stored in
SQLite, and password sessions share the existing account, eight-hour lifetime,
recent-authentication checks and revocation controls. Changing or disabling the
password revokes its sessions; at least one passkey must remain available.
