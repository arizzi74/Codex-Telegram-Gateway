Remove bot

Removing a bot from this gateway deletes its local bot records, chat bindings and notification subscriptions. Worker sessions and project files will be kept. The bot stays on Telegram until its owner deletes it in BotFather.

Enroll a worker

Run the installer on the worker machine. Enter a display name there, then paste this one-use URL. It expires in 10 minutes. Opening it in a browser does not use it.

Installer command

Run as the developer account that owns your projects, without sudo:

curl -fsSL https://raw.githubusercontent.com/arizzi74/Codex-Telegram-Gateway/main/scripts/install.sh | sh

For older installers. Current Linux setup asks “Restrict this worker service?” on the worker machine; that local answer determines access. Yes (default) blocks sudo; no uses existing account permissions and sudo rules. macOS uses normal account permissions.
